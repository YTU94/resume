### 企业自建应用 · Skill 接入方案
`钉钉 · 2025 — 2026` · **角色：方案主导 / 核心开发**

帮助企业将内部系统（OA / ERP / CRM）低门槛接入钉钉 Agent：用户正常操作目标网站，系统自动采集并理解接口行为，生成可直接挂载应用的可执行 Skill。

**方案原理**
- 采用类 **OpenCLI** 的浏览器监听方案，在用户操作目标网站期间，自动采集时段内全部接口请求
- 经 **AI 总结加工**，识别接口语义、参数结构与调用关系，输出可直接挂载应用的可操作 Skill

**我的核心贡献**
- **Skill 自动生成链路**：主导浏览器侧请求采集、AI 加工与 Skill 发布全流程设计，定义 Skill Manifest 规范（类 OpenAPI）统一参数、鉴权与调用约束
- **登录态治理**：针对各站点登录机制差异，收敛 **Cookie** 与常见 **access_token** 两类 Session 管理；叠加时效探针检测，失效时引导用户更新登录态
- **产出稳定性保障**：采用**文件契约**约定 Skill 产出目录与文件结构，配套自动化校验流水线，生成结果稳定性达 **95%+**
- **低码场景攻坚**：识别低码平台动态表单接口语义难以推断的问题，评估 Drive UI 结合 DOM 意图分析方案，平衡准确率与实现成本

**技术难点**
- **登录态标准化**：难以用单一方案适配所有网站登录机制，以 Cookie / access_token 双轨管理 + 探针检测 + 用户引导更新作为可扩展实践
- **生成结果稳定性**：通过文件契约约束必备产出物，并执行自动化检测 gate，显著降低 AI 输出波动
- **接口语义识别**：低码平台动态表单 API 用途模糊，可借助 Drive UI 获取 DOM 推断意图，但实现成本较高，作为备选增强路径
